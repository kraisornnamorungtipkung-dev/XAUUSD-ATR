Methodology & Formula Reference
Volume Fuel Status Vol / SMA20
วอลุ่มแท่งปัจจุบันเปรียบเทียบกับค่าเฉลี่ย 20 แท่ง ถ้า Vol > SMA20 หมายความว่าตลาดมีแรงซื้อขายเกินค่าปกติ สนับสนุนทิศทางราคา
Fuel ON : Vol > Vol_SMA20 Ratio : Vol / Vol_SMA20 Signal : Ratio > 1.0 → FUEL ON
Volatility Multiplier ATR 1W Distance
วัดว่าระยะห่างระหว่างราคาปัจจุบันกับเป้าหมายเป็นกี่เท่าของ ATR 1W เพื่อประเมิน "ความไกล" ของเป้าหมายในแง่ Volatility
VM = |Target − Current| / ATR_1W < 1x : Low Distance 1-2x : Moderate 2-3x : High Momentum ≥ 3x : Extreme Extension
SD Zone (2.6σ) 99th Percentile
ใช้ 2.6σ เป็น "High Tension" threshold เพราะบน Normal Distribution ราคาที่อยู่ห่างจากค่ากลาง 2.6σ จะเกิดขึ้นน้อยกว่า 1% ของเวลาทั้งหมด — บ่งชี้ภาวะ Overbought/Oversold รุนแรง
P(X > 2.6σ) ≈ 0.46% (one-tail) Normal : < 1.5σ Moderate : 1.5 – 2.0σ Elevated : 2.0 – 2.6σ Hi-Tens : 2.6 – 3.0σ Overpriced: > 3.0σ
MA12 Coefficient (0.25) Empirical Calibration
ค่า Coeff 0.25 ได้จากการ calibrate บนข้อมูล SPX และ XAUUSD ย้อนหลัง — โดยพบว่า MA12 หักออก 0.25 × ATR 1W ให้ระดับ Support ที่ราคามักเด้งกลับจากบริเวณนั้นบ่อยที่สุด
MA12_Support_1W = MA12_Base − (0.25 × ATR_1W) MA12_Support_1M = Base_Price − (0.188 × ATR_1M)
Volatility Extension SD × ATR
คำนวณระดับราคา Resistance โดยนำ Base Price บวกด้วย SD Value คูณ ATR 1D เป็นการประมาณว่าราคาจะ "ยืดออก" ไปได้ไกลแค่ไหนในกรอบ Volatility ปัจจุบัน
Vol_Extension = Base_Price + (SD × ATR_1D) เช่น: 4406 + (2.0 × 172) = 4750
Momentum Acceleration Accel × ATR
ระดับ Resistance ถัดไปถ้าราคา Breakout ผ่าน Volatility Extension ไปแล้ว Accel Coeff ควรมากกว่า SD Value เสมอเพื่อให้ Momentum Level อยู่สูงกว่า
Mom_Level = Base_Price + (Accel × ATR_1D) Accel (default 2.6) > SD Value (default 2.0) เช่น: 4406 + (2.6 × 172) = 4853.2
